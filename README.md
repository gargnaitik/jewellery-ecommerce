# 💍 Jewellery E-Commerce Platform

A full-stack jewellery marketplace inspired by Tanishq — with live gold pricing, 
product catalogue, order management, and payment integration.

## Tech Stack
- **Backend**: NestJS, PostgreSQL, MongoDB, Redis
- **Frontend**: Next.js, TailwindCSS (WIP)
- **Infra**: Docker, AWS S3, Kafka

## Features
- [ ] User auth with OTP
- [ ] Product catalogue with filters
- [ ] Live gold rate pricing engine
- [ ] Razorpay payment integration
- [ ] Order tracking

## Getting Started
\`\`\`bash
cd backend
npm install
cp .env.example .env
npm run start:dev
\`\`\`
